A Python program (standard library only) that draws one newspaper front page summing up the world news of Friday 13 November 2026 — Ukraine's biggest drone night as peace talks widen, U.S. forces downing Iranian drones and a tanker mine in Hormuz, Nvidia's chief resigning, the Microsoft 365 outage, China's unannounced Pacific drills, the Gaza hospital strike, and the IEA oil surplus — and writes it to entry.png as a hand-encoded PNG. Deterministic: every run produces byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
